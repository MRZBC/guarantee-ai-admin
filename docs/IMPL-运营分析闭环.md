## 已实现

- `OrderReportService`：按申请日期汇总订单数、担保金额、保费；本期与前一等长周期对比。
  日期限定 1–366 天；默认以已知数据结束日取最近最多 30 天。零基数显示新增/无变化，
  比较超出已知覆盖时不生成提醒；订单数满足上期 ≥20 且绝对变化率 ≥30% 才提示。
  阈值以未舍入数值判断，所有数值由服务端计算，页面不推断原因。
- `order-report` 在一个可重复读事务中返回比较、趋势与地区/险种/机构分布，避免页面多请求口径漂移。
  明确区分全库概览与当前筛选摘要；未加载的概览显示骨架，避免把未加载伪装成零。
- 图表携带原始标识支持点击下钻，同时提供表格“查看订单”入口；类型/日期/地区/机构保留在 URL。
  订单页支持刷新、返回、重置；响应序号避免旧慢请求覆盖新结果；缓存页面离开后不再随无关路由查询。
- CSV 聚合摘要：UTF-8 BOM、日期与筛选、生成时间、指标单位、Top 10 标识；处理引号/换行与文本公式防护。
  新权限 `analysis:export`，默认仅 ADMIN/ANALYST；服务端同时检查分析查看权限。
- WEB/EXPORT/ANALYSIS_REPORT 审计复用既有 `WebAuditor` 端口，记录条件、条数和 traceId，无文件正文。
  导出失败或拒绝不会下发 CSV；该目标的审计仅管理员可查。
- Playwright 关键流程入口 `frontend/e2e/analysis.spec.ts`；CI Job1 增加前端构建与浏览器回归，
  AI 用例拦截模型与确认写接口，不调用真实模型、不修改业务主数据。失败保留截图/trace/HTML 报告。

## OA-01 口径核对结果

| 项 | 实现事实与处理 |
|---|---|
| 日期 | 两类订单与分析都用 apply_date，首尾包含；比较接口共用分析的 orderSource/criteriaFilter |
| 删除 | 订单主表显式 is_deleted=0；维度名称沿用既有历史保留口径，不增加内连接导致订单消失 |
| 地区 | 图表按完整编码分组，订单普通筛选按 RegionCodePrefix 层级匹配；新增 regionExact=true 使下钻严格对齐分组 |
| 机构 | 既有机构榜实际 GROUP BY org_id, region_code，界面标为“机构与地区排行”；下钻必须同时传两个条件 |
| JOIN | 维度表主键关联，不通过显示名称反查；事务内样本证明分组与订单计数一致 |
| 权限 | 现有订单/分析 SQL 未实施按用户机构过滤；机构是外部承保机构，并非用户归属。本轮不臆造新的行级范围；新增读取/导出入口强制检查权限码 |
| 排序 | 地区/机构榜增加编码排序作为并列时的稳定次序，降低重复查询或导出的排序漂移 |

## 唯一全量回归失败：既有未跟踪知识条目与 GQ-22 冲突

失败位置：`EvaluationDeterministicIT.gq22`，问题“保证金退还流程是怎样的？”。
既有断言要求未收录问题没有知识来源，但实际出现 `KB-CONCEPT-0002《电子保函：概念与制度背景》v1`。

该 Markdown 在本轮开始前已是未跟踪文件；本轮未修改它，也未修改知识检索、提示词或评测断言。
正常启动/测试的既有导入器会扫描所有 classpath 知识资源，因此本机知识数从发布基线 18 变成 19。
知识库确已导入该条目，不能通过关闭导入、跳过 GQ-22 或移除用户文件将失败包装成通过。

下一步先核实该条目是否应发布，再独立处理错误命中或知识条目口径，保留 GQ-22 的拒绝虚构要求并复跑。
本轮不扩展到知识检索策略改造；此冲突登记为发布阻塞。真实模型未调用，也未声称真机回归通过。

## 本地复核与演示

1. 启动 MySQL/Redis，使用 `scripts/mvn-locked.ps1` 运行相关 Maven 检查。
2. 先打包，再启动临时后端 8093；后端实例持有 jar 期间不要重复 repackage。
3. 前端目录运行 `npm ci`、`npx playwright install chromium`、`npm run test:e2e`。
   Playwright 使用独立 Vite 5278，默认代理 8093；CI 失败产物位于 test-results/playwright-report。
4. 登录 admin/analyst → 数据概览，比较两个明确区间；从地区/险种/机构图表或表格查看订单，刷新再返回；导出摘要。
   登录 operator 时不展示导出入口，直接调用导出接口也被拒绝。
5. 新权限需重新登录或刷新当前用户权限后显示；存量部署可执行 V11，服务默认也会幂等补齐。

不推送、不发布。原有未跟踪知识文件保持原状；临时验证实例用后停止，避免遗留 jar 锁。

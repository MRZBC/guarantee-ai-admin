# Edge 验收整改迭代（2026-10-25）

依据：`edge-live-acceptance-2026-10-25.md` 与 `edge-live-remediation-plan-2026-10-25.md`。

## 实现

- E2：`RoleQueryTool` 仅将 keyword 传给统一编码 OR 名称搜索，显式 roleCode 独立传递，不再回填 roleName。状态、删除可见性及权限校验继续生效。
- E1：本轮工具事实增加真实名称和前后值采集；执行声明防护只在引用/字段值位置排除这些已知值，保留引用之外的完成声明检查。规则描述、删除记录筛选标签和修饰记录的状态不作为本次执行声明；按转折与分句检查，避免前半句否定掩盖后半句假成功。
- E3：最终模型 system 消息追加服务端当前账号动作权限摘要。无权限时明确联系管理员，不能仅因助手工具缺席推断页面可修改。该摘要在已发布/内置提示词组装之后加入，无须直接改写数据库发布版本。
- 提案载荷补充 resultMessage、auditId、executedAt，来自已保存的提案实体。
- 前端保留终态并收起明细，展示结果、时间和审计编号；有 `system:audit:view` 时提供审计页入口。失效不再统一解释成权限变化，具体原因由后端结果展示。
- 历史恢复显式使用 `status=ALL`（服务端转为无状态过滤），避免 HTTP 空字符串被 PENDING 默认值替换。保留会话过滤、结果去重及服务端数量上限；晚到的其他会话响应不合并到当前会话。
- 普通角色改名不再附带无关的编码拦截警告；不可变编码的服务端约束不变。
- 登录与布局将不存在的 Shield 图标替换为已注册的 Lock。

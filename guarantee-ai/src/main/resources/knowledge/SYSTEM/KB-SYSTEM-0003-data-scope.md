**数据范围不再按机构收敛**：现阶段，已登录用户的数据范围恒为全量，不随其所在机构变化；
按层级收敛的数据范围会在后续以权限码重建。

因此不要把"某机构的数据"理解成"某机构的人能看到的数据"——机构是订单的维度，
不是人的可见范围。
